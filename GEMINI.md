# FinTrack - Assistant Instructions

## UI & Design Guidelines
- Always read and adhere to [DESIGN.md](file:///Users/allanindrajith/Github%20Project/FinTrack/DESIGN.md) when creating, styling, or refactoring UI components and pages.
- Use the **Wise-inspired design system** tokens:
  - **Colors**: Wise Green primary (`#9fe870`), Sage canvas-soft (`#e8ebe6`), Ink text (`#0e0f0c`), and semantic status colors.
  - **Typography**: Wise Sans / Inter weight 900 for hero displays, Inter weight 600 for sub-displays, weight 400 for body.
  - **Shapes**: Canonical card and button border radius is `24px` (`rounded-xl` / pill-rounded).
